# Third-party components

This project uses Next.js, React, Three.js / React Three Fiber, Tailwind CSS, Supabase JavaScript, and MapLibre GL JS. Package versions and licenses are recorded by `package-lock.json` and the installed package manifests.

The decoder files in `public/draco/` are distributed with Three.js. Draco is licensed under Apache License 2.0 by Google. Source: <https://github.com/google/draco>. Three.js is MIT licensed: <https://github.com/mrdoob/three.js>.

The corresponding license texts are included in `public/draco/LICENSE` and `public/draco/THREE-LICENSE`.

OpenStreetMap raster tiles are loaded only when the user opens a registered location's map. Map attribution links to <https://www.openstreetmap.org/copyright>.

The cat paw model, its Blender source, cat-face SVGs, and all screenshots are created for this repository. Screenshots contain fictional test data only.
